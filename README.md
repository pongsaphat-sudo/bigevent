# Bigevent Organizer Website

เว็บออแกไนเซอร์พร้อมหน้าบ้านและหลังบ้าน ใช้ PHP + SQLite/MySQL + Tailwind CSS

## สิ่งที่มีในระบบ

- หน้าบ้าน: หน้าแรก, เกี่ยวกับบริษัท, ผลงาน, บทความ, ติดต่อ
- แสดงแบนเนอร์ Hero, ผลงานบริษัท, โลโก้ลูกค้า, บทความ
- หลังบ้าน: ล็อกอินแอดมิน, จัดการแบนเนอร์, ผลงาน, โลโก้ลูกค้า, บทความ
- อัปโหลดรูปภาพลงโฟลเดอร์ `uploads/`
- ระบบ E-Catalog หลายเล่ม พร้อมหน้ารวม หน้ารายละเอียด ตัวอ่าน PDF แบบพลิกหน้าบนเว็บ และดาวน์โหลด PDF
- ฐานข้อมูล SQLite สำหรับ local หรือ MySQL/MariaDB สำหรับ production

## วิธีรัน

```bash
php -d auto_prepend_file= -S localhost:8000 index.php
```

เปิดเว็บที่ `http://localhost:8000`

## รันด้วย Docker + MariaDB สำหรับ local development

```bash
docker compose -p bigevent-local up -d --build
```

เปิดเว็บที่ `http://localhost:8088` โค้ดและโฟลเดอร์ `uploads/` จะถูก mount จากโปรเจกต์นี้โดยตรง ส่วนฐานข้อมูลเก็บใน Docker volume ชื่อ `bigevent-local_bigevent-db`

CSS, ฟอนต์ Prompt/Inter และไอคอนหลักถูกเสิร์ฟจากโปรเจกต์ ไม่ต้องเรียก Tailwind CDN, Google Fonts หรือ unpkg ในหน้าเว็บ หากแก้คลาส Tailwind ให้สร้าง CSS ใหม่ด้วย `npm ci && npm run build:css` ก่อนทดสอบ/นำขึ้นเซิร์ฟเวอร์ และนำ `assets/css/tailwind.generated.css` กับ `assets/vendor/` ไปด้วย

ภาพหน้าแรกมี WebP หลายขนาดและโหลดเมื่อเลื่อนถึงภาพ หลังนำเข้าภาพเก่าจำนวนมากให้รัน `node scripts/build-responsive-images.mjs` ขณะ local web ทำงานเพื่อสร้างภาพขนาด 480/960px; ภาพที่อัปโหลดใหม่ระบบจะสร้างขนาดย่ออัตโนมัติ

## หน้าแรกและเมนูหลัก

- เมนูหน้าบ้านใช้ header เดียวกันทุกหน้า รองรับจอใหญ่และเมนูแบบเปิด–ปิดบนจอเล็ก พร้อมลิงก์ภาษาไทย/อังกฤษ
- สไลด์หน้าแรกดึงผลงานที่เลือก `แสดงในหน้าแรก` สูงสุด 5 รายการ โดยเรียงจาก `วันที่เผยแพร่บนเว็บไซต์` ใหม่สุด; แถบผลงานด้านล่างแสดง 8 รายการล่าสุดและไม่ขยับเมื่อเปลี่ยนสไลด์
- ในหลังบ้านส่วนผลงาน ใส่ `ชื่อสั้นบนสไลด์หน้าแรก` และ `คำโปรยสั้นบนสไลด์หน้าแรก` แยกไทย/อังกฤษเพื่อให้ข้อความกระชับ; หากเว้นว่าง ระบบจะย่อจากชื่อและรายละเอียดผลงานเดิม
- ผู้ชมกดหยุดสไลด์ได้ และระบบหยุดอัตโนมัติเมื่อเอาเมาส์ชี้/โฟกัสสไลด์หรือเปิดโหมดลดการเคลื่อนไหว
- ฐานข้อมูลตรวจการเปลี่ยน schema เมื่อเวอร์ชัน migration เปลี่ยนเท่านั้น เพื่อไม่ให้คำขอหน้าเว็บต้องตรวจคอลัมน์ทั้งหมดทุกครั้ง

## จัดการ E-Catalog

- หลังบ้าน: `http://localhost:8088/admin/ecatalog`
- หน้ารวม: `http://localhost:8088/ecatalog`
- เพิ่มชื่อ รายละเอียด ลูกค้า หมวดหมู่ และ SEO ได้ทั้งภาษาไทยและอังกฤษ
- อัปโหลดรูปปกและ PDF ขนาดไม่เกิน 200 MB; PDF เก็บใน `storage/ecatalog-pdfs/` และเปิดอ่านด้วยตัวอ่านบนเว็บไซต์ (PDF.js ที่เก็บใน `assets/vendor/pdfjs/`) โดยไม่ต้องฝังเว็บอื่น
- production บน Plesk ต้องตั้ง PHP `upload_max_filesize` อย่างน้อย `200M` และ `post_max_size` มากกว่า 200M (แนะนำ `220M`); ค่าของ Docker local กำหนดไว้ใน `Dockerfile`
- ตัวอ่านรองรับหน้าคู่บนเดสก์ท็อป หน้าเดี่ยวบนมือถือ, พลิกหน้า, ดูภาพย่อทุกหน้า, ซูม, เต็มหน้าจอ, คีย์บอร์ด/ปัดหน้าจอ และดาวน์โหลด
- PDF จะเริ่มโหลดเมื่อผู้อ่านเลื่อนใกล้ตัวอ่าน, แสดงหน้าที่ 1 ก่อน แล้วค่อยเตรียมหน้าอื่น; PDF ที่เผยแพร่มี ETag/Last-Modified สำหรับแคช หากเปลี่ยนไฟล์โดยตรงให้เก็บต้นฉบับแยกไว้เสมอ
- ถ้า PDF ใหม่มีรูปความละเอียดสูงและไฟล์ใหญ่ ให้บีบอัดก่อนอัปโหลดด้วย `scripts/optimize-catalog-pdf.py` (ต้องติดตั้ง `pikepdf` และ `Pillow`); วิธีนี้เปลี่ยนเฉพาะรูปใน PDF และคงโครงสร้างหน้ากับข้อความ จากนั้นตรวจภาพและจำนวนหน้าเทียบต้นฉบับก่อนเผยแพร่
- URL หนังสือจาก FlipHTML5 หรือผู้ให้บริการอื่นใช้สำหรับเล่มเก่าที่ไม่มี PDF เท่านั้น; หากมีทั้งสองอย่าง ระบบเลือก PDF
- ตัวอย่าง local: `http://localhost:8088/ecatalog/bigevent-services-2026` (ไฟล์ตัวอย่างอยู่ในเครื่องนี้และฐานข้อมูล Docker local; ยังไม่ได้เผยแพร่ขึ้นโฮสต์จริง)
- หน้าแรกแสดงเป็นชั้นหนังสือสูงสุด 6 เล่ม โดยต้องเปิดทั้ง `เผยแพร่บนหน้าบ้าน` และ `แสดงเป็นรายการแนะนำหน้าแรก` ในฟอร์มหลังบ้าน; เล่มใหม่จะไม่ขึ้นหน้าแรกหากยังไม่เลือกสองสถานะนี้
- ชั้นหนังสือเรียงตาม `ลำดับการแสดง` จากเลขน้อยไปมาก; หากเลขเท่ากัน เรียงวันที่เผยแพร่ใหม่ก่อน (แล้วตามด้วยรายการที่เพิ่มล่าสุด)
- URL เก่า `/ecatalog-sisaket` จะ redirect ไปยังรายการ Sisaket ในระบบใหม่

## ใช้ MySQL/MariaDB บนเซิร์ฟเวอร์

1. สร้างฐานข้อมูลและ user ใน Plesk
2. คัดลอก `config.example.php` เป็น `config.php`
3. แก้ค่า `db_name`, `db_user`, `db_password` ให้ตรงกับ Plesk
4. เปิดเว็บ 1 ครั้ง ระบบจะสร้างตารางอัตโนมัติ
5. ถ้าต้องย้ายข้อมูลจาก SQLite เดิม ให้นำไฟล์ `storage/mysql-import.sql` ไป import ผ่าน phpMyAdmin หลังตารางถูกสร้างแล้ว

ตัวอย่าง `config.php` จะไม่ถูก commit ขึ้น Git เพื่อไม่ให้รหัสผ่านฐานข้อมูลหลุด
